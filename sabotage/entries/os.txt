# Sockets, polling and the waker (crates/curl-os, feature `net`).

=== a signal ending a poll early is an error
file: crates/curl-os/src/poll.rs
witness: curl-os poll::tests::an_interrupted_wait_reports_nothing_ready
--- old
        if err.kind() == io::ErrorKind::Interrupted {
            return Ok(0);
        }
--- new

=== a poll timeout is rounded down to whole milliseconds
file: crates/curl-os/src/poll.rs
witness: curl-os poll::tests::a_sub_millisecond_timeout_still_waits
--- old
    let ms = timeout.as_nanos().div_ceil(1_000_000);
--- new
    let ms = timeout.as_nanos() / 1_000_000;

=== a wake into a full pipe is an error
file: crates/curl-os/src/wake.rs
witness: curl-os wake::tests::waking_more_than_the_pipe_holds_is_fine
--- old
                Ok(_) => return Ok(()),
                Err(e) if e.kind() == io::ErrorKind::Interrupted => {}
                Err(e) if e.kind() == io::ErrorKind::WouldBlock => return Ok(()),
--- new
                Ok(_) => return Ok(()),
                Err(e) if e.kind() == io::ErrorKind::Interrupted => {}
